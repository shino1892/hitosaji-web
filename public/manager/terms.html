ひとさじマネージャー 利用規約

2026年10月17日 制定・2026年10月19日 改定（緊急停止のお知らせと、ボットを強制退出させたときの扱いを追記）

この規約は、ひとさじマネージャー（以下「本サービス」）を使う配信者（以下「利用者」）と、本サービスを運営する個人（ハンドル名: shino。以下「運営者」）との間の決まりです。本サービスの管理画面にログインした時点で、この規約とプライバシーポリシーに同意したものとします。

第1条　本サービスについて

  1. 本サービスは、Spoon 公式の Spoon Developers API を使い、利用者が連携した配信に、ボット「ひとさじBot」を参加させるものです。ボットは、利用者が選んだ機能と文面で、チャットにあいさつ、お礼、コマンドへの返答、定期的な案内を送ります。
  2. 本サービスは個人が運営するもので、Spoon 公式のサービスではありません。Spoon を運営する会社は、本サービスについて責任を負いません。
  3. 本サービスは無料です。

第2条　利用の条件

  1. 本サービスを使えるのは、自分が配信に使う Spoon のアカウントで連携する人だけです。他人のアカウントで連携してはいけません。
  2. 利用者は、Spoon の利用規約と、そのほかの Spoon のルールを守って本サービスを使ってください。
  3. ボットが配信に参加していることは、Spoon が配信のチャットで自動的にお知らせします。この告知を妨げたり、隠したりしてはいけません。
  4. Spoon の仕組みにより、ボットは一度配信に入ると、応答を止めたあともリスナー一覧に残ります。ボットを強制退出させると、Spoon がボットのアカウントを自動でブロックするため、ブロックを解除して連携し直すまで本サービスを使えなくなります。

第3条　利用者が登録する文面

  1. あいさつ・お礼の文面、カスタムコマンドの返答、定期的な案内など、利用者が登録した文面（以下「登録文面」）は、ボットの名前でチャットに送られます。登録文面の内容は、利用者が責任を持ってください。
  2. 運営者は、本サービスを守るため、登録文面を確認することがあります。また、特定の言葉を含む文面を送らない・保存させない仕組み（NG ワード）を設けています。

第4条　禁止事項

利用者は、本サービスを使って次のことをしてはいけません。

  1. 法令、公序良俗、Spoon の利用規約に反すること
  2. 他人を傷つける、差別する、脅す、嫌がらせをする内容や、わいせつな内容を送らせること
  3. 他人や団体になりすますこと、Spoon 公式や運営者からの案内のように見せかけること
  4. 宣伝や勧誘、外部のサイトへの誘導を、リスナーの迷惑になるほど繰り返すこと
  5. リスナーの個人情報を集めたり、さらしたりすること
  6. 本サービスや Spoon に過度な負荷をかけること、不正にアクセスすること、仕組みを解析して悪用すること
  7. そのほか、運営者が本サービスの運営に支障があると判断すること

第5条　利用の停止とデータの削除

  1. 利用者が前条に当たる行為をしたとき、または当たるおそれがあると運営者が判断したときは、運営者は事前に知らせずに、その利用者の本サービスの利用を止め、連携とデータを削除することがあります。
  2. 利用者は、管理画面からいつでも Spoon との連携を解除し、アカウントを削除できます。連携を解除したときと、アカウントを削除したときのデータの扱いは、プライバシーポリシーのとおりです。

第6条　本サービスの変更・中断・終了

  1. 運営者は、事前に知らせずに、本サービスの内容を変えたり、本サービスを一時的に止めたりすることがあります。保守、障害、Spoon の仕様の変更などで、ボットが配信に参加できない・チャットを送れないことがあります。
  2. ボットの不具合などで急いで止める必要があるときは、運営者は、すべての配信でボットの応答を止めることがあります（緊急停止）。このとき、ボットが動いている配信のチャットに「【緊急メンテナンス】」で始まるお知らせを送り、管理画面にも表示します。
  3. 運営者は、本サービスの提供を終えることがあります。終えるときは、できるだけ前もって、このサイトでお知らせします。提供を終えたときは、保存しているデータを削除します。

第7条　保証しないこと・責任の範囲

  1. 本サービスは、その時点の状態のまま提供します。運営者は、本サービスが利用者の目的に合うこと、正しく動き続けること、不具合がないことを保証しません。
  2. 運営者は、本サービスを使ったこと、または使えなかったことで利用者に生じた損害について、運営者に故意または重大な過失がある場合を除き、責任を負いません。
  3. 利用者と、リスナーやほかの利用者との間で起きた争いは、当事者の間で解決してください。

第8条　規約の変更

運営者は、必要に応じてこの規約を変えることがあります。変えるときは、このページを更新し、上に改定日を記載します。変えたあとも本サービスを使い続けた場合は、変えた規約に同意したものとします。

第9条　準拠法

この規約は、日本の法律に従って解釈します。

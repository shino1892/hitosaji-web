ひとさじマネージャー

Spoon の配信者が自分の配信に招く、マネージャーボットです。

使い始めるには、2つの手順があります。

  1. 管理画面に Google でログイン。管理画面に入るためのもので、Spoon のログインではありません（Spoon に X などでログインしている人も使えます）
  2. Spoon と連携。ふだんと同じ方法で、配信に使っている Spoon のアカウントにログインします

連携すると、次の配信からボットが入ります。

管理画面にログイン

使い方とよくある質問（はじめかた、配信中に使えるコマンド）

できること

  • 入室のあいさつ（はじめまして・いらっしゃい・おかえりなさい）
  • ハートとスプーンへのお礼
  • 遊びコマンド: !おみくじ !サイコロ !じゃんけん グー !コイン !えらんで A B !相性 ◯◯ !ヘルプ
  • 配信者が登録したコマンドへの返答（例: !sns で SNS の案内）
  • リスナーごと・グループごとのあいさつとお礼（例: 常連さんには特別なひとこと）
  • 配信者が登録した定期的な案内（5〜180分ごと。いくつでも登録でき、1つずつオン・オフできます）

どの機能もオン・オフでき、あいさつやお礼の文面は配信者が自由に変えられます。

配信者の方へ

  • 管理画面に Google でログインし、Spoon の配信者アカウントと連携して使います（Google の表示名やメールアドレスは受け取りません）
  • 使う前に利用規約をお読みください。ログインすると同意したものとします
  • 入室のあいさつを使うには、ひとさじBot をマネージャーにしてください（固定マネージャーなら毎回、臨時マネージャーならその配信の間だけ）
  • 連携の解除とアカウントの削除は、管理画面からいつでもできます。解除すると、保存していた情報はすべて削除します

リスナーの方へ

  • チャットの本文は保存しません。ニックネームは、配信者が管理画面でリスナーを選べるように、最後に来てから1年だけ保存します
  • あいさつやお礼がいらないときは、チャットで !あいさつ不要 と送ってください（!あいさつ再開 で戻せます）

使い方は使い方とよくある質問、くわしい決まりはひとさじマネージャーの利用規約とプライバシーポリシーをご覧ください。

ひとさじBot は、Spoon 公式の Spoon Developers API を使って個人が運営しているボットです。Spoon 公式のサービスではありません。

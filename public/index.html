🥄 ひとさじBot

Spoon の配信に、ひとさじの応援を届ける自動で動くボットです（中の人はいません）。

Spoon 公式の Spoon Developers API を使って、個人（shino）が作って運営しています。Spoon 公式のサービスではありません。

できること

  • 配信者がオンにしているとき、入室のあいさつや、ハート・ギフトへのお礼をチャットでお送りします
  • おみくじなどの遊びコマンドや、配信者が登録したコマンドに返答します（準備中）
  • 配信者が自分の配信を振り返るための集計をお手伝いします

安心して使ってもらうために

  • 配信者が自分で Spoon 公式の画面から連携を許可した配信にだけ入ります
  • ボットが参加していることは、Spoon が配信のチャットで自動でお知らせします
  • チャットの本文は保存しません

くわしくは利用規約とプライバシーポリシーをご覧ください。

ひとさじマネージャー

配信者が自分の配信に招くマネージャーボットです。あいさつ、お礼、遊びコマンド、登録したコマンドへの返答、定期的な案内をまかせられます。ただいま準備中です（審査中のため Spoon との連携はまだできませんが、ログインして設定を用意しておけます）。
